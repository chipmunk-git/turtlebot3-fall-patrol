개인 음성·서버 / 로봇 통합 실행 안내
========================================

Ubuntu Desktop 서버 PC 작업 경로: ~/robotech/project_ws/
Pi 자체 개발 프로그램의 목표 경로와 기존 ROBOTIS 환경 구분은 README.md의
'실행 환경과 작업 경로'를 따른다. Pi 새 경로로의 배치·실행은 아직 검증되지 않았다.

실제 로봇의 전체 실행 순서(순찰·음성·LED·LCD)와 확인 결과는 docs/HANDOVER.md를 따른다.

[A] 개인 개발 환경
----------------------------------------
환경 생성·설치·활성화·설치 확인과 로컬 서버 실행 명령은
README.md의 '개인 개발 환경 (Python 3.10)'에 모았다.
개인 저장소 위치는 각자의 실제 경로를 사용한다.
STT 단독 실행·안내 재생 후 인식·입력 장치 선택·모의 테스트 명령은
voice/README.md를 참고한다.

아래 [B]는 Ubuntu/ROS2와 실제 로봇·카메라를 위한 기존 실행 절차다.
개인 음성·서버 개발에서는 [A]를 사용한다.

[B] Ubuntu/ROS2 - 실행 방법 (카메라 + 대시보드)
========================================

[1] Raspberry Pi 터미널: 기존 ROBOTIS bringup + 카메라
----------------------------------------
먼저 로봇에 접속(ROBOT_IP를 실제 로봇 주소로 변경):
ssh ubuntu@ROBOT_IP

아래는 기존 ~/turtlebot3_ws/가 빌드되어 있고 카메라 패키지도 준비된 환경 기준이다.
기존 ROBOTIS 작업공간을 유지하며, Pi 자체 개발용 목표 경로로 옮기는 절차가 아니다.
접속 후 기존 ROS2 환경을 불러오고 실행한다. NUCLEO 등 다른 USB 장치가 함께 연결되면
기본값 /dev/ttyACM0이 OpenCR이 아닐 수 있으므로 usb_port를 고유 경로로 지정한다.
source /opt/ros/humble/setup.bash
source ~/turtlebot3_ws/install/setup.bash
ros2 run v4l2_camera v4l2_camera_node > /dev/null 2>&1 & ros2 launch turtlebot3_bringup robot.launch.py usb_port:=$(ls /dev/serial/by-id/usb-ROBOTIS_OpenCR*)

끄기: Ctrl+C (bringup 종료) 후
pkill -f v4l2_camera


[2] Ubuntu Desktop 서버 PC 터미널: 서버 + 영상
----------------------------------------
web_video_server가 현재 PC의 ROS2 환경에 준비되고 Pi의 카메라 토픽을 수신하는 전제다.
web_video_server가 설치되어 있지 않으면 다음 명령으로 설치한다.
sudo apt install ros-humble-web-video-server
별도 ROS2 오버레이를 사용한다면 해당 환경도 먼저 불러온다.
source /opt/ros/humble/setup.bash
cd ~/robotech/project_ws
ros2 run web_video_server web_video_server > /dev/null 2>&1 &
cd backend
.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000

끄기: Ctrl+C (서버 종료) 후
pkill -f web_video_server


[3] 브라우저
----------------------------------------
이 PC:      http://localhost:8000
다른 기기:  http://SERVER_IP:8000 (SERVER_IP를 Ubuntu 서버 PC의 실제 주소로 변경)


[4] Ubuntu Desktop 서버 PC 별도 터미널: 실기 순찰용 위치 추정
----------------------------------------
실제 순찰을 함께 실행할 때 사용한다. my_bot_fall을 먼저 빌드하고,
src/maps/new_map.yaml과 new_map.pgm을 이 PC의 같은 폴더에 함께 둔다.
빌드와 자세·순찰·Pi 음성 실행의 전체 순서는 src/my_bot_fall/README.md를 참고한다.
기존 지도 서버·AMCL 또는 SLAM이 실행 중이면 중복 실행하지 않는다.

cd ~/robotech/project_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch my_bot_fall tb3_localization_real.launch.py \
  map:="$PWD/src/maps/new_map.yaml" \
  use_sim_time:=false

map 인자는 필수이며 다른 작업 경로에서는 실제 YAML의 절대 경로를 지정한다.
src/maps/는 colcon 설치 대상이 아니다. backend/maps/는 웹 표시용 가공 지도다.
RViz에서 2D Pose Estimate로 실제 초기 위치·방향을 맞춘 뒤 자세·순찰 노드를 실행한다.
끄기: Ctrl+C (위치 추정·RViz 종료)


참고
----------------------------------------
- 로봇과 PC의 ROS_DOMAIN_ID가 같아야 함 (지금 33). 확인: echo $ROS_DOMAIN_ID
- 카메라·대시보드는 실행 순서와 무관하게 연결됨. 대시보드는 영상이 끊기면 5초마다 다시 연결함
- 영상이 안 나오면 대시보드에서 F5 (안 되면 Ctrl+Shift+R)
- localhost:8080에서 /image_raw 원본 토픽을 누르지 말 것 (와이파이가 꽉 차서 영상이 멈춤)
- "주소가 이미 사용 중(address already in use)" 에러가 나면 이미 떠 있는 것:
  pkill -f "uvicorn app.main:app"; pkill -f web_video_server
